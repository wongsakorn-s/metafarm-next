# MetaFarm Next: สถานะเทียบระบบเดิมและแผนส่งมอบ

อัปเดต 29 กันยายน 2026 คำว่า “ผ่าน” ในเอกสารนี้หมายถึงตรวจด้วยชุดทดสอบในเครื่องและ smoke test กับ Neon development branch เท่านั้น ยังไม่ใช่การยืนยันบน staging หรือ production

## ขอบเขตที่ตกลง

- หน้าเว็บสาธารณะเปิดอ่านได้โดยไม่ต้องล็อกอิน หลังบ้านสำหรับ owner และ staff เท่านั้น
- ยังไม่ย้ายข้อมูลจริงจาก `metafarm-management-app`; ข้อมูลในสองระบบยังแยกกัน
- ยังไม่เผยแพร่เบอร์โทร อีเมล หรือช่องทาง social ของฟาร์มที่ไม่ได้รับการยืนยัน
- ไม่มีระบบขายสินค้า และไม่มี offline write queue

## งานต่อก่อนปล่อยจริง

1. ทดสอบบนมือถือจริง: ฟอร์มหน้างาน กล้อง QR, รูปจากกล้อง, สิทธิ์กล้อง, สัญญาณอ่อน, การพิมพ์ A4 และขนาดจอ 320–1440 px
2. เพิ่ม E2E บน staging สำหรับ owner/staff, การเพิ่มรัง/ผลผลิต/การตรวจ/รูป, การปิดสิทธิ์ทีม และการเปิดลิงก์รายละเอียดจาก QR โดยใช้ข้อมูลทดสอบที่ลบได้
3. เพิ่มตัวกรองวันที่และการส่งออกข้อมูลเพื่อสำรอง; ประเมิน cursor pagination เมื่อมีข้อมูลจำนวนมากหรือเขียนพร้อมกันบ่อย
4. ตัดสินใจเรื่องลบรัง/เก็บถาวร: ระบบเดิมลบรังได้ แต่ระบบใหม่ยังไม่ให้ลบเพื่อลดความเสี่ยงต่อประวัติ ต้องกำหนดกฎธุรกิจก่อนเพิ่ม mutation นี้
5. ตรวจความจำเป็นของข้อมูลอากาศ: ระบบเดิมมี endpoint อากาศและ mock fallback; ระบบใหม่ยังไม่ใส่ข้อมูลจำลองบนหน้าจริง ต้องเลือกแหล่งข้อมูลและนโยบายเมื่อแหล่งข้อมูลล่ม
6. ตรวจเนื้อหาสาธารณะกับเจ้าของฟาร์ม รวมถึงรูปความละเอียดสูงและช่องทางติดต่อที่ยืนยันแล้ว; วัด Lighthouse Mobile และแก้ตามผลจริง
7. หลังรีวิวโค้ด ให้ส่งขึ้น staging และทดสอบสิทธิ์/ข้อมูล/สื่อจาก URL จริง จากนั้นจึงปล่อย production ผ่าน workflow แยก พร้อมแผน rollback

## สิ่งที่ไม่ทำในรอบนี้

- ไม่ย้ายข้อมูลรัง ผลผลิต การตรวจ รูป หรือบัญชีจากระบบเก่าเข้าสู่ระบบใหม่
- ไม่เพิ่ม role viewer
- ไม่เปิด production หรือใช้ข้อมูลจริงเป็นข้อมูลทดสอบ

หากภายหลังต้องการย้ายข้อมูล ให้ทำ exporter, mapping ID, ตรวจจำนวน/รูป, dry-run และแผน rollback บน staging ก่อนขออนุมัติย้ายจริงอีกครั้ง
