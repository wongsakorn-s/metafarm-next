# การทดสอบหน้างาน Phase 3

สถานะ: ยังไม่ได้ทดสอบบนอุปกรณ์จริง (30 กันยายน 2026) การผ่าน Playwright บน Chromium desktop ไม่ทดแทนผลบน Android Chrome หรือ iOS Safari

## ขั้นตอนที่ต้องตรวจบน staging

| อุปกรณ์/กรณี | สิ่งที่ต้องตรวจ | ผล |
| --- | --- | --- |
| Android Chrome กล้องหลัง | สแกนป้าย URL ใหม่และรหัสเก่า เปิดรังถูกต้อง | รอทดสอบ |
| iOS Safari กล้องหลัง | สแกนป้าย URL ใหม่และรหัสเก่า เปิดรังถูกต้อง | รอทดสอบ |
| Android Chrome/iOS Safari | ปฏิเสธสิทธิ์กล้องแล้วแจ้งเหตุผลและใช้ช่องกรอกรหัสแทนได้ | รอทดสอบ |
| Android Chrome/iOS Safari | ถ่ายรูป บันทึกตรวจ ดู progress และลองอัปโหลดซ้ำเมื่อเครือข่ายล้มเหลว | รอทดสอบ |
| Android Chrome/iOS Safari | สัญญาณอ่อน: กดบันทึกซ้ำโดยใช้ Idempotency-Key เดิม ได้รายการเดียว | รอทดสอบ |
| Android Chrome/iOS Safari | ปิดแท็บก่อนบันทึก เปิดใหม่แล้ว draft ข้อความยังอยู่ | รอทดสอบ |
| เครื่องพิมพ์ A4 | ตรวจ print preview ว่าป้าย 3 คอลัมน์ × 8 แถว อ่าน QR ได้จริง | รอทดสอบ |

ห้ามใส่ข้อมูลจริงของฟาร์มในผลทดสอบ; ใช้รังทดสอบที่ลบหรือเก็บถาวรได้ และบันทึกวันที่ รุ่นอุปกรณ์/เบราว์เซอร์ ผลจริง และปัญหาที่พบเมื่อทดสอบ
